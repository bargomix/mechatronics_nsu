# ПР02. Пакет и запуск turtlesim

[Задание](https://ros.lms.ci.nsu.ru/practices/pr02).
Среда: Docker, Ubuntu 24.04, ROS 2 Jazzy. Образ закреплён в
`docker-image.txt`, course kit — в `course-kit.lock.json`.
Пакет `turtle_bringup` устанавливает `launch/sim.launch.py`, который запускает
готовую ноду `/turtlesim`. Собственной ноды и teleop в launch нет.

## Подготовка

На хосте из корня репозитория:

```bash
./scripts/docker-start.sh
./scripts/ros-shell.sh
```

Контейнер подключает репозиторий как `/work`, X11/XWayland и cookie сессии.
В новых терминалах B и C также выполните `./scripts/ros-shell.sh`.
Базовая ROS подключается автоматически; начальный `ROS_DOMAIN_ID=16`.
В аудитории замените его выделенным вам доменом во всех терминалах.
Перед опытом остановите прежние turtlesim и teleop.

## Сборка

В свежем терминале контейнера, с подключённой только базовой ROS:

```bash
cd /work
source /opt/ros/jazzy/setup.bash
mkdir -p evidence/pr02
set -o pipefail
colcon build --symlink-install --packages-select turtle_bringup \
  2>&1 | tee evidence/pr02/build.txt
```

Первоначальная сборка пустого пакета сохранена в `build-empty.txt`.
Не перезаписывайте этот лог: текущие исходники уже содержат launch.

## Запуск и остановка

В A:

```bash
source install/setup.bash
ros2 pkg prefix turtle_bringup
ls "$(ros2 pkg prefix turtle_bringup)/share/turtle_bringup/launch"
ros2 launch turtle_bringup sim.launch.py
```

В C проверьте `ros2 node list --no-daemon --spin-time 2`.
В A нажмите Ctrl+C и убедитесь из C, что `/turtlesim` исчезла.
Затем повторно запустите тот же launch. Должно открыться одно окно.

## Команда и движение

Во всех терминалах `export ROS_DOMAIN_ID=16`; teleop остановлен.
В C:

```bash
ros2 interface show geometry_msgs/msg/Twist
ros2 topic type /turtle1/pose
ros2 topic echo /turtle1/pose --once
```

В B:

```bash
ros2 topic pub --once /turtle1/cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 1.0}, angular: {z: 0.5}}'
```

Через две секунды повторите echo позы в C. Черепаха идёт вперёд по дуге
против часовой стрелки, а после прекращения команд останавливается.

## Сбой имени и исправление

В B:

```bash
ros2 topic pub --rate 1 --wait-matching-subscriptions 0 \
  /cmd_vel geometry_msgs/msg/Twist \
  '{linear: {x: 1.0}, angular: {z: 0.5}}'
```

В C, пока издатель работает:

```bash
ros2 topic info /cmd_vel --verbose
ros2 topic info /turtle1/cmd_vel --verbose
ros2 topic echo /turtle1/pose --once
```

Издатель `/cmd_vel` обнаруживается, но у этого топика нет подписчика.
У `/turtle1/cmd_vel` есть подписчик `/turtlesim`, но нет издателя.
Черепаха стоит: одинакового типа Twist недостаточно для доставки.

В B нажмите Ctrl+C, замените **только** `/cmd_vel` на `/turtle1/cmd_vel`
и повторите команду с теми же скоростями, частотой и доменом. Проверьте
конечные точки и изменение позы. После наблюдения остановите издателя,
подождите две секунды и проверьте нулевые скорости.

Файл `sim.launch.py` на диске — описание запуска; `/turtlesim` — работающий
процесс с ROS-нодой; Twist — отдельное сообщение команды в графе.
Сборка и `source` сами по себе не запускают ноду.

## Проверка и сдача

Реальные команды и вывод: [commands.md](../evidence/pr02/commands.md).
Типы сообщений: [types.md](../evidence/pr02/types.md).
Отчёт: [report.json](../evidence/pr02/report.json).
Декларация ИИ: [AI_USAGE.md](../AI_USAGE.md).

```bash
python3 -m py_compile src/turtle_bringup/launch/sim.launch.py
python3 .course-kit/v1/tools/check_practice.py PR02 --submission .
```

Если kit отсутствует, скачайте `archive_url` из `course-kit.lock.json`,
проверьте его `sha256` и распакуйте архив в `.course-kit/`.
CI использует те же URL и SHA-256, собирает пакет в закреплённом ROS-образе,
проверяет установленный launch-файл и запускает checker PR02.
GUI, движение и завершение процесса проверяются локально.

По правилам курса коммит A содержит пакет, README и CI; коммит B —
`evidence/pr02/` и `AI_USAGE.md`, а `report.commit` хранит SHA(A).
Для сдачи нужны ссылка на репозиторий, полный SHA(B) и успешный CI run для B.

По завершении остановите launch через Ctrl+C. Контейнер можно остановить
на хосте командой `docker stop mechatronics-pr01`.
