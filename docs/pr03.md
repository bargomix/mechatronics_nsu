# ПР03. Первая нода: поза и команда

[Задание](https://ros.lms.ci.nsu.ru/practices/pr03).
Среда прежняя: Docker, ROS 2 Jazzy, домен 16. Пакет `turtle_bringup`
из ПР02 запускает turtlesim, новый пакет `patrol` — нашу ноду.

## Сборка и тесты

На хосте из корня репозитория:

```bash
./scripts/docker-start.sh
./scripts/ros-shell.sh
```

В контейнере, в свежем терминале с базовой ROS:

```bash
source /opt/ros/jazzy/setup.bash
colcon build --symlink-install --packages-select turtle_bringup patrol
source install/setup.bash
python3 -m pytest src/patrol/test
```

`patrol` зависит от `rclpy`, `geometry_msgs` и `turtlesim`: в нашей установке
тип позы — `turtlesim/msg/Pose`. Callback подписки сохраняет последнее
сообщение, таймер каждые 0,1 с публикует результат чистой функции
`choose_command`. До первой позы команда нулевая, после —
`linear.x=0.5`, `angular.z=0.3`.

## Повтор опыта

Во всех терминалах контейнера подключите ROS, overlay и один домен:

```bash
source /opt/ros/jazzy/setup.bash
source install/setup.bash
export ROS_DOMAIN_ID=16
```

Остановите прежние patrol, teleop и turtlesim. В A:

```bash
ros2 launch turtle_bringup sim.launch.py
```

В B сначала запустите исправный вариант:

```bash
ros2 run patrol patrol --ros-args -r cmd_vel:=/turtle1/cmd_vel
```

В C проверьте граф, тип позы и движение:

```bash
ros2 node list --no-daemon --spin-time 2
ros2 node info /patrol
ros2 topic type /turtle1/pose
ros2 topic echo /turtle1/pose --once
```

Остановите patrol в B через Ctrl+C и подождите две секунды: turtlesim
останавливается по таймауту последней команды. Затем воспроизведите сбой:

```bash
ros2 run patrol patrol
```

В C:

```bash
ros2 topic info /cmd_vel --verbose
ros2 topic info /turtle1/cmd_vel --verbose
ros2 topic echo /cmd_vel --once
ros2 topic echo /turtle1/pose --once
```

У `/cmd_vel` один издатель `/patrol`, но нет подписчика turtlesim.
Нода получает позу и выдаёт ненулевой Twist, однако черепаха стоит.
Повторите чтение позы и убедитесь, что координаты не изменились.

Остановите patrol в B и верните только remap:

```bash
ros2 run patrol patrol --ros-args -r cmd_vel:=/turtle1/cmd_vel
```

Проверьте endpoint и позу теми же командами с правильным именем топика:

```bash
ros2 node info /patrol
ros2 topic info /turtle1/cmd_vel --verbose
ros2 topic echo /turtle1/cmd_vel --once
ros2 topic echo /turtle1/pose --once
timeout --signal=INT --kill-after=3s 10s ros2 topic hz /turtle1/cmd_vel
```

Последняя команда работает 10 секунд; ожидаемый код `timeout` — 124.
Частота должна быть близка к 10 Гц, точный результат запишите из вывода.
При ручном запуске без `timeout` подождите 10 секунд и нажмите Ctrl+C.
После остановки patrol дождитесь нулевых скоростей и повторите чтение позы.
Затем остановите launch в A.

## Автоматизированный повтор

В контейнере после сборки и `source install/setup.bash`:

```bash
python3 scripts/pr03-experiment.py --output .local/pr03-repeat
```

Скрипт требует пустой граф в выбранном домене, запускает реальные процессы,
проверяет нулевую команду до первой позы, движение, ошибку имени, remap,
частоту и остановку. Вывод команд сохраняется в указанную папку.
По умолчанию результат сохраняется в `evidence/pr03/`; для повтора используйте
отдельный каталог, чтобы сохранить первоначальные логи.
