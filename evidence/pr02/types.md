# PR02: топики и типы

Фактическая среда — ROS 2 Jazzy; типы получены через CLI, а не выбраны
по названию дистрибутива: [topics.txt](topics.txt), [pose-type.txt](pose-type.txt).

| Полное имя | Тип | Направление и назначение |
| --- | --- | --- |
| `/turtle1/cmd_vel` | `geometry_msgs/msg/Twist` | CLI-издатель → `/turtlesim`: команда скорости |
| `/turtle1/pose` | `turtlesim/msg/Pose` | `/turtlesim` → CLI-наблюдатель: положение и скорости |

Во время сбоя дополнительно существовал `/cmd_vel` того же типа Twist,
но у него не было подписчика turtlesim. Имя `/cmd_vel` не совпадает
с `/turtle1/cmd_vel`: ROS не сопоставляет эти топики по общему суффиксу.

## geometry_msgs/msg/Twist

Проверка: `ros2 interface show geometry_msgs/msg/Twist`;
точный вывод — [twist.txt](twist.txt).

Два поля `linear` и `angular` имеют тип `geometry_msgs/msg/Vector3`.
Каждый Vector3 содержит три поля `float64`: `x`, `y`, `z`.

| Поле | Смысл | Использование в turtlesim |
| --- | --- | --- |
| `linear.x` | Линейная скорость вдоль локальной оси x, м/с | Движение вперёд; в опыте `1.0` |
| `linear.y`, `linear.z` | Линейные скорости по другим осям | В данном плоском симуляторе не используются |
| `angular.x`, `angular.y` | Угловые скорости вокруг осей x и y | В данном симуляторе не используются |
| `angular.z` | Угловая скорость вокруг z, рад/с | Поворот; `0.5` против часовой стрелки |

В YAML `{linear: {x: 1.0}, angular: {z: 0.5}}` пропущенные компоненты
инициализируются нулями. Для плоского движения ненулевые `linear.x` и
`angular.z` задают дугу. Twist не содержит позиции, длительности движения
или имени целевого топика — топик задаётся отдельно при публикации.

## turtlesim/msg/Pose

`ros2 topic type /turtle1/pose` вернула `turtlesim/msg/Pose`.
Проверка интерфейса: `ros2 interface show turtlesim/msg/Pose`;
вывод — [pose-interface.txt](pose-interface.txt).

Все пять полей имеют тип `float32`:

| Поле | Смысл |
| --- | --- |
| `x`, `y` | Координаты в плоскости симулятора, м |
| `theta` | Угол направления, рад |
| `linear_velocity` | Текущая линейная скорость, м/с |
| `angular_velocity` | Текущая угловая скорость, рад/с |

Одиночная команда меняет x, y и theta, но без дальнейших команд симулятор
останавливается. Поэтому после ожидания в позе скорости равны нулю.
Сопоставление поз до/после доказывает движение, а ненулевые скорости
во время исправленной непрерывной публикации подтверждают доставку команд.
